# 🛡️ Defensive Security

Esta sección reúne prácticas y documentación relacionadas con la **seguridad defensiva**, enfocadas en la protección, monitoreo y análisis de sistemas.

Aquí se incluirán temas como detección de amenazas, análisis de eventos, respuesta a incidentes, monitoreo de seguridad y uso de herramientas orientadas a Blue Team.

El contenido se irá ampliando con nuevas prácticas y proyectos.
