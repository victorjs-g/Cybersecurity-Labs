Repositorio académico enfocado en **Infrastructure Systems**, administración de servidores, automatización, servicios de red y despliegue de infraestructura basada en Linux.

Este espacio reúne prácticas relacionadas con Ubuntu Server, Ansible, Docker, Active Directory con Samba, servicios DNS y DHCP, alta disponibilidad y administración de sistemas.
