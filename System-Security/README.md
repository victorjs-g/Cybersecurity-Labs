Repositorio académico enfocado en **System Security**, hardening de sistemas e implementación de configuraciones seguras en entornos Windows y Linux.

Este espacio reúne prácticas relacionadas con protección de sistemas operativos, Active Directory, autenticación, cifrado, análisis de vulnerabilidades, infraestructura segura y aplicación de controles defensivos.
