Repositorio académico enfocado en **Offensive Security y Ethical Hacking**, orientado a la práctica de técnicas utilizadas durante evaluaciones de seguridad y pruebas de penetración en entornos controlados.

Este espacio reúne prácticas relacionadas con reconocimiento, explotación de vulnerabilidades, ataques contra servicios de red, seguridad de aplicaciones web y análisis de diferentes vectores de ataque.

## Documentación

| Práctica / Documento                                        | Descripción                                                                                                                                | Formato |
| ----------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------- |
| [Ataque DoS en bWAPP](./Ataque_DOS_Bwapp.pdf)               | Práctica enfocada en la ejecución y análisis de un ataque de denegación de servicio dentro de un entorno vulnerable controlado.            | PDF     |
| [Ataque de Fuerza Bruta SSH](./Ataque_Fuerza_Bruta_SSH.pdf) | Evaluación de un servicio SSH mediante técnicas de fuerza bruta y análisis de credenciales.                                                | PDF     |
| [Infectando una Imagen](./Infectando_Una_Imagen.pdf)        | Práctica orientada al análisis de técnicas utilizadas para incorporar contenido malicioso dentro de archivos y estudiar su comportamiento. | PDF     |
| [Kali Attack to Windows 10](./Kali_Attack_To_Windows10.pdf) | Laboratorio práctico de evaluación y explotación de un sistema Windows 10 desde Kali Linux dentro de un entorno controlado.                | PDF     |
